0614 Desplegament d'aplicacions Web Protocol FTP FTP ⟶ File Transfer protocol Protocol que proporciona el servei de transferència de fitxers entre sistemes de diferent naturalesa. El protocol tal com es coneix s’especifica dins la RFC 959 l’any 1985, posteriorment s’ha anat revisant amb algunes noves característiques, però la seva base ha estat mantinguda. El protocol FTP es basa en l’arquitectura client/servidor i fa ús del protocol de control (TCP) de transport per realitzar el canal de transmissió entre el client i el servidor.

0614 Desplegament d'aplicacions Web Protocol FTP Es fan servir dos canals de comunicació El canal de control: Envia totes les ordres de comunicació, per exemple la d’iniciar la sessió de treball, llegir, escriure, etc. Fa servir el port 21 El canal de dades: envia el contingut d’aquells fitxers a treballar, que pot ser tant per llegir el contingut del fitxer com per fer l’escriptura. Fa servir el port 20 Tant el client com el servidor gestionen dos processos: PTD (process de transferencia de dades): és l’encarregat d’establir la connexió i administrar el canal de dades. IP (Intèrpret de Protocol): interpreta el protocol i permet que el PTD pugui ser controlat mitjançant ordres rebudes pel canal de control.

0614 Desplegament d'aplicacions Web Protocol FTP L’IP és diferent en el client i servidor, cadascú s’encarrega d’unes funcions específiques. L’IP del servidor: Escolta les ordres que provenen de l’IP de l’usuari mitjançant el canal de control per un port de dades. Estableix la connexió del canal de control. Rep les ordres FTP de l’IP de l’usuari, les respon i executa al PTD del servidor. L’IP del client: És el responsable d’establir la connexió amb el servidor FTP. Envia ordres FTP. Rep les respostes del servidor IP. Controla el PTD de l’usuari.

0614 Desplegament d'aplicacions Web Funcionament FTP El client envia ordres FTP al servidor, el servidor les interpreta, executa el PTD i respon amb un format estàndard. Un cop establerta la connexió, l’IP del servidor proporciona el port que es farà servir per enviar les dades PTD al client. Tota la comunicació que es fa en el canal de control segueix les recomanacions del protocol Telnet: serveix per accedir de forma remota a un altre equip i controlar-lo mitjançant ordres de text.

0614 Desplegament d'aplicacions Web Funcionament FTP Les ordres FTP permeten especificar: El port que es farà servir. El mètode de transferència de dades. L’estructura de dades L’acció que es durà a terme (llegir, eliminar, llistar, etc.)

0614 Desplegament d'aplicacions Web Funcionament FTP Hi ha tres distribucions d’ordres FTP Ordres de control d’accés: especifiquen els identificadors del control d’accés. La majoria d’aquests controlen qui accedeix al servidor FTP i quins privilegis tindrà l’usuari. Ordres de paràmetres de transferència: tenen un valor per defecte del servidor FTP, i només es fa ús d’aquests paràmetres si han estat modificades. No es tracta només de "pujar o baixar", sinó de configurar el format del fitxer, l'estructura i la manera en què s'empaqueten els bits. Ordres de servei FTP: Defineixen la transferència de fitxers i la navegació dels directoris remots per a l’usuari. L’argument principal de les ordres de servei sol ser el nom d’un directori. Totes les dades que s’envien per a una ordre de servei sempre s’envien pel canal de dades.

0614 Desplegament d'aplicacions Web Funcionament FTP - Resum PTD: És el responsable d'establir la connexió i administrar directament el canal de dades. IP (Intèrpret de Protocol): Controla el PTD mitjançant les ordres rebudes pel canal de control. IP del Servidor: Escolta les ordres, estableix la connexió de control i executa les accions en el seu PTD. IP del Client: Estableix la connexió amb el servidor, envia les ordres i controla el seu propi PTD.

0614 Desplegament d'aplicacions Web Tipus d’usuaris Usuaris del sistema: usuari propi del sistema on hi ha el servei FTP i que accedeix al seu directori personal. Usuari anònim: usuari que no té contrasenya de validació i d’accés públic al servei. Usuari virtual: Aquest deriva dels usuaris del sistema, però amb la diferència que només depenen del FTP

0614 Desplegament d'aplicacions Web Mode FTP actiu El client connecta aleatòriament per un port més gran de 1024 (anomenem-lo N) cap al port 21 d’ordres del servidor. El client inicia l’escolta al port (N+1) i envia l’ordre FTP al port (N+1) del servidor. FTP. El servidor connecta de nou al client pel port de dades especificat per part del client, que és el port 20. Quan treballeu en mode actiu es té en compte el tallafoc del sistema. El tallafoc ha de tenir els ports oberts de treball del servidor i del client, per poder establir les comunicacions.

0614 Desplegament d'aplicacions Web Mode FTP passiu El client inicia les dues connexions al servidor, resolent el problema de control del tallafoc en el filtratge del port de dades en el servidor cap al client.

El client, a l’iniciar la connexió FTP, agafa un port aleatori més gran de 1024 N i el següent com N + 1. El primer port N fa la connexió pel port 21 del servidor i evita fer la connexió al port de dades 20. El client farà ús d’una ordre PASV. El servidor obre un port aleatori P més gran de 1024 i li retorna al client amb l’ordre PASV. El client inicia el canal de dades del port (N + 1) al port P.

0614 Desplegament d'aplicacions Web FTPS El protocol FTPS fa ús d’SSL, TLS i és una combinació d’algoritmes de xifrat asimètrics, algoritmes simètrics i un algoritme d’intercanvi de claus amb autenticació de certificats X.509. Hi ha dos modes de FTPS: Mode implícit: es requereix una sessió SSL entre el client i el servidor abans que s'intercanviï qualsevol dada. Mode explícit: El client i el servidor negocien el nivell de protecció que es farà servir.

0614 Desplegament d'aplicacions Web SFTP SFTP està basat en SSH (secure shell), protocol conegut per proveir seguretat als terminals remots. No fa ús de canals d’ordres i de dades. Totes les dades enviades i rebudes són encriptades mitjançant un algoritme d’encriptació prèviament acordat. Les sessions estan protegides mitjançant claus públiques i privades, que ofereixen un sistema d’autenticació conegut com a autenticació de clau pública que es pot fer servir com a alternativa o unió dels sistemes d’autenticació tradicionals de noms d’usuari i contrasenyes.
