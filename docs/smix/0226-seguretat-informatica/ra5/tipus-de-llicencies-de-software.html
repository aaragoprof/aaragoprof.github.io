GESTIÓ I LEGALITAT DE PROGRAMARI Tipus de Llicències de Software Programari no lliure OEM, Retail, Volum) vs Programari Lliure GPL, BSD, MPL, Copyleft)

PROGRAMARI PROPIETARI Llicències de Programari No Lliure OEM Original Equipment Manufacturer No es pot vendre aïlladament. Ve vinculat directament al maquinari que l'incorpora des de fàbrica. RETAIL Venda Estàndard Versions comercialitzades normalment en Caixes o botigues. Transferible a qualsevol equip compatible. Per Volum Empreses i Institucions Llicències per a organitzacions (escoles, universitats). Similars a OEM però no lligades a un equip concret.

FONAMENTS DEL SOFTWARE LLIURE Les 4 Llibertats Fonamentals Lliure no vol dir Gratuto: Discord, Chrome o Spotify són gratuïts Freeware), però NO són programari lliure. 1. Ús Llibertat per executar el programa per a qualsevol propòsit. 2. Estudi Llibertat d'estudiar el codi font i adaptar-lo a les necessitats. 3. Redistribució Llibertat per redistribuir còpies per ajudar a altres usuaris. 4. Millora Pública Llibertat per millorar el programa i fer públiques les millores.

MODELS DE LLICÈNCIES LLIURES GPL, BSD i MPL GPL Recíproca Estricta: Si modifiques el codi, no el pots "tancar" ni vendre com a propi. Quina millora faci ha de romandre lliure per a tothom. BSD Permissiva: Permet modificar i vendre el resultat com a propi, requerint només donar crèdit a l'autor original en una nota. MPL Mozilla Public License: Permet utilitzar el nucli del programa, fer-hi millores i posar-lo a la venda sense publicar les adaptacions privades.

EL CONCEPTE CLAU El Concepte de Copyleft Copyright vs Copyleft Joc de paraules legal: Irrevocabilitat Un autor no pot fer marxa enrere: un cop ha alliberat un programa sota una llicència lliure, no pot cancel·lar els drets concedits ni convertir aquesta versió en de pagament. • Copyright: Serveix per a prohibir la còpia i distribució. • Copyleft: Serveix per a garantir que tothom tingui dret a copiar i compartir.

Resum de Llicències de Software Tria la llicència adequada segons les necessitats del teu projecte: OEM / Retail / Volum per al control propietari tradicional. GPL / BSD / MPL per compartir el codi amb diferents graus de restricció i llibertat.
