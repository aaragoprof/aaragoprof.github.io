0614 Desplegament d'aplicacions Web Servidors web Servidors capaços de gestionar i donar accés a recursos estàtics (documents HTML, imatges, vídeos, etc.) com a resposta a peticions de clients. Aquests recursos s'emmagatzemen com a fitxers al servidor. La majoria de servidors web moderns permeten la instal·lació de mòduls per generar continguts dinàmics mitjançant l'execució de codi (PHP, Javascript, Python, etc.). Aquesta funcionalitat, però, és més característica dels servidors d'aplicacions. Exemple Apache HTTP Server (per a sistemes operatius Linux) i Microsoft Internet Information Server (IIS) (per a Windows). En resum, un servidor web actua com a punt d'intercanvi de dades basat en HTTP, inicialment per a contingut fix, però actualment ampliat per gestionar la generació de contingut variable.

Servidors d’aplicacions 0614 Desplegament d'aplicacions Web La funció del Servidor d'Aplicacions és crear o generar el contingut de manera dinàmica abans de servir-lo. Penseu-hi com el cuiner que agafa ingredients (dades), segueix una recepta (el codi de l'aplicació) i munta un plat personalitzat. Què fa? Executa programes (escrits en PHP, Java, Python, .NET, etc.) i realitza lògiques complexes (com ara consultar una base de dades, processar un pagament, o verificar una sessió d'usuari). Com ho fa? S'encarrega d'executar el codi de l'aplicació i de generar el document HTML final a temps real com a resposta a la petició del client. Contingut: És personalitzat. Si 100 usuaris miren la seva bústia de correu, cadascú veu contingut diferent, generat dinàmicament pel servidor d'aplicacions. Serveis Addicionals: Ofereix eines essencials per a aplicacions complexes (gestió de transaccions, seguretat, persistència de dades, etc.).

0614 Desplegament d'aplicacions Web Servidors de fitxers És un servidor que permet gestionar a través de xarxa la càrrega, descàrrega, actualització i eliminació de fitxers emmagatzemats en els seus dispositius des d’ordinadors client. Els servidors de fitxers s’utilitzen principalment per desplegar les aplicacions sobre el servidor on s’executaran. El desplegament comporta habitualment la càrrega de grans quantitats de fitxers sobre aquets servidors. Un dels protocols més usats és el protocol FTPS i SFTP

Coding School Servidors de directori Permet gestionar informació administrativa respecte a l’entorn d’una aplicació web, com poden ser, per exemple, els usuaris autoritzats amb els seus rols o permisos, etc. La utilitat principal dels servidors de directori és facilitar la gestió d’informació relativa a l’explotació d’aplicacions web. L’avantatge de gestionar aquesta informació mitjançant aquest tipus de servidors és la centralització de dades i la facilitat d’accés mitjançant protocols estàndard com LDAP.
